# ハイジャンプ選手権（カメラ版）

公開URL: https://pa314960-prog.github.io/kaken.high.jump/

カメラの前で本当に走って、跳んで、バンザイして、ジャンプの高さを競うブラウザゲームです。
プロジェクターで前に大きく映して、みんなで順番に遊ぶことを想定しています。

## あそびかた

カメラから 2〜3m 離れて、**腰から上（できればひざまで）** が写るように立ちます。

1. **スタート**：両手を上げて約1秒キープ 🙌（「準備OK！」ボタン / スペースキーでも可）
2. **助走（4秒）**：その場でももを高く上げて全力足ぶみ！スピードゲージがたまる
3. **踏み切り**：左右に動くマーカーがまん中（赤）に来たら **本当にジャンプ**
   - タイミング：PERFECT ×1.6 / GREAT ×1.3 / GOOD ×1.0 / MISS ×0.6
   - リアルジャンプ：実際に腰が上がった高さでさらに倍率アップ（結果に「約○cm」と表示）
4. **空中ジャンプ**：頂上付近でスローになり、黄色い輪が縮んでくる。点線の輪に重なった瞬間に **バンザイ**！

一軒家・観覧車・東京タワー・スカイツリー・熱気球・ジェット機…富士山（3776m）を目指そう。

## 機能

- 1〜4人の順番対戦、1回勝負 / 3回勝負
- 他のプレイヤーの記録・自己ベスト・歴代1位が点線で表示される
- 歴代ランキング TOP10（ブラウザに保存）
- 画面右下にカメラ映像（鏡映し）と骨格を表示。白い点線＝立っているときの腰、赤い点線＝ここを超えたらジャンプ判定
- 全画面：右上のボタン または Fキー
- カメラが使えないときは、スペースキー / 画面タップで遊べる（連打で助走、押して踏み切り・空中ジャンプ）

## プロジェクターで使うときのコツ

- 横長の画面（16:9）向けにレイアウトしています。ブラウザを全画面（Fキー）にしてください
- カメラは人の正面・腰くらいの高さに置くと判定が安定します
- 後ろを人が横切ったり、2人以上写ったりすると誤判定しやすいので、跳ぶ人だけが写るようにしてください
- 明るい場所のほうが認識が安定します

## 起動

カメラを使うため **https または localhost** で開く必要があります。GitHub Pages ならそのまま動きます。
ローカルで動かすときは簡易サーバーを使ってください。

```bash
python -m http.server 8000
# → http://localhost:8000 を開く
```

姿勢検出（MediaPipe Pose Landmarker Lite）のライブラリとモデルは `vendor/` に同梱しているので、ネット接続なしでも動きます。
カメラ映像はすべてブラウザ内で処理され、外部には送信されません。
