# 最高到達点チャレンジ

公開URL: https://pa314960-prog.github.io/kaken.high.jump/

カメラの前で本当にジャンプして、**指先がどこまで届いたか（cm）** を競うゲームです。
プロジェクターで壁に目盛りを大きく映し、跳んでいる人の「影」を実寸で重ねて表示します。

## あそびかた

1. タイトルで人数・制限時間（10秒 / 20秒）・競うもの（到達点 / ジャンプ力）を選び、名前と**身長**を入れる
2. カメラから3〜4m離れて、**頭から足まで全身**（手を上げた指先まで）が写る位置に立つ
3. **両手をまっすぐ上に伸ばして止まる**と、立ったときの指先の高さを測る
4. 3・2・1のあと、制限時間のあいだ何回でもジャンプ！一番高かった記録が残る
5. 全員終わったら結果発表。歴代ランキング（到達点 / ジャンプ力）にも残る

- **到達点**：ジャンプして指先が届いた高さ（例：254cm）
- **ジャンプ力**：立ったときの指先より何cm高く跳べたか（垂直跳び）

壁には目安として「ドアの高さ 200cm」「バレーネット 224 / 243cm」「バスケットゴール 305cm」、ほかの人の記録、歴代1位の線が出ます。

## しくみ

- MediaPipe Pose で体の位置を検出
- 身長と「鼻〜足首の長さ」から、画面上の長さを cm に換算
- 跳んだ高さは**腰がどれだけ上がったか**で測る（ジャンプ中に手が画面の外に出ても測れる）
- 到達点 ＝ 立ったときの指先の高さ ＋ 跳んだ高さ

身長を正しく入れるほど cm が正確になります。

## 設置のコツ（プロジェクター）

- 横長（16:9）の画面向け。ブラウザを全画面に（右上のボタン / Fキー）
- カメラは跳ぶ人の正面、腰〜胸くらいの高さに置き、全身と上げた手が入るように少し離す
- 跳ぶ位置を床にテープなどで決めておくと、カメラからの距離が変わらず測定が安定する
- 跳ぶ人以外が写らないように（後ろを人が通ると誤判定しやすい）
- 右下の小さな映像は操作する人向けのカメラ確認用。骨格が緑なら全身が写っている

## 起動

カメラを使うため **https または localhost** で開いてください。GitHub Pages ならそのまま動きます。

```bash
python -m http.server 8000
# → http://localhost:8000 を開く
```

姿勢検出のライブラリとモデルは `vendor/` に同梱しているので、ネット接続なしでも動きます。
カメラ映像はすべてブラウザ内で処理され、外部には送信されません。
