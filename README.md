# ハイジャンプ選手権

ジャンプの高さを競うブラウザゲームです。1〜4人で順番に跳んで、いちばん高く跳んだ人の勝ち！

## あそびかた（スペースキー / 画面タップ）

1. **助走**：3秒間とにかく連打してスピードをためる
2. **踏み切り**：左右に動くマーカーがまん中（赤）に来たら押す
   - PERFECT ×1.6 / GREAT ×1.3 / GOOD ×1.0 / MISS ×0.6
   - 助走が速いほどマーカーも速くなる
3. **空中ジャンプ**：頂上付近でスローになり、黄色い輪が縮んでくる。点線の輪に重なった瞬間に押すともう一段上昇

一軒家・観覧車・東京タワー・スカイツリー…と、どこまで超えられるか挑戦しよう。

## 機能

- 1〜4人の順番対戦、1回勝負 / 3回勝負
- 他のプレイヤーの記録・自己ベスト・歴代1位が点線で表示される
- 歴代ランキング TOP10（ブラウザに保存）
- スマホ対応（タップ操作）

## 起動

`index.html` をブラウザで開くだけで遊べます（サーバー不要）。
